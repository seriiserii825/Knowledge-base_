# Claude Code — голосовой ввод (voice mode)

## Что это
Режим "hold-to-talk" в Claude Code CLI (терминал): зажимаешь пробел — идёт запись с микрофона, отпускаешь — текст распознаётся и подставляется в промпт.

## Как включить/выключить
Команда в самом Claude Code:
```
/voice
```
Переключает состояние (enabled/disabled), сообщает в чат текущий режим, например:
```
Voice mode enabled (hold). Hold space to record.
```

## Где хранится настройка
Файл: `~/.claude/settings.json`

Нужный блок:
```json
{
  "voice": {
    "enabled": true,
    "mode": "hold"
  },
  "voiceEnabled": true
}
```
- `voice.enabled` / `voiceEnabled` — включён ли голосовой ввод.
- `voice.mode` — `"hold"` = зажать пробел для записи (hold-to-talk).

Чтобы перенести настройку на другую машину — скопировать этот блок в `~/.claude/settings.json` на новом компьютере (или весь файл целиком, если нет других специфичных для машины настроек).

## Требования для работы
1. Микрофон должен быть подключён и выбран как **default source** в системе.
   Проверка на Linux (PipeWire/Pulse):
   ```bash
   pactl info | grep -i "default source"
   pactl list short sources
   ```
2. Терминал должен иметь доступ к микрофону на уровне ОС (актуально для macOS — System Settings → Privacy & Security → Microphone → разрешить приложению терминала).
3. Важно: это НЕ связано с расширением Claude in Chrome — доступ микрофона в Chrome (chrome://settings/content/microphone) нужен только для голосового ввода на сайте claude.ai в браузере, а не для Claude Code CLI в терминале. Это два разных механизма, их легко перепутать.

## Системный файл настройки звука (ALSA → PipeWire)
Файл: `~/.asoundrc`

Указывает ALSA использовать PipeWire как default для вывода и записи звука:
```
pcm.!default {
    type pipewire
}
ctl.!default {
    type pipewire
}
```
Без этого файла (или при другом содержимом) приложения, работающие через ALSA напрямую, могут не видеть микрофон/звук через PipeWire — соответственно и голосовой ввод в Claude Code может не работать.

Чтобы перенести на другую машину — скопировать этот файл в `~/.asoundrc` (нужен установленный `pipewire-alsa` / `pipewire-pulse`).

## Если не работает
- Проверить, что `/voice` действительно показывает "enabled" перед использованием.
- Проверить, что зажат именно пробел (а не другая клавиша) и что фокус находится в окне терминала с Claude Code.
- Проверить микрофон системно (см. `pactl` выше) — убедиться, что нужное устройство выбрано как default source и не заглушено.
- Если использовался не тот терминал/машина — проверить, что `~/.claude/settings.json` там тоже содержит блок `voice`.
