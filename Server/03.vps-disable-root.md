# 03. Отключить вход под root и по паролю

Цель: на сервер можно зайти **только по ключу** и **только не под root**.

Перед этим: `02.vps-server-ssh-keys.md` — вход `ssh vps` (или `ssh -i ... node@<IP>`) по ключу **уже работает**.

> ⚠️ Держите открытой одну SSH-сессию до конца проверки (шаг 5). Если что-то сломается — исправите через неё. Если всё
> же потеряли доступ — у провайдера есть веб-консоль (OVH: Bare Metal Cloud → VPS → KVM; Hetzner: Console).

## Шаг 1. Проверить, что вход по ключу работает

В **новом** терминале:

```bash
ssh vps
sudo whoami   # → root
```

Если спрашивает пароль пользователя (не passphrase ключа) — ключ не настроен, вернитесь к `02`.

## Шаг 2. Свой файл настроек

На Ubuntu основной `/etc/ssh/sshd_config` в начале подключает `/etc/ssh/sshd_config.d/*.conf`, и **для каждого параметра
побеждает первое найденное значение**. У облачных провайдеров там часто лежит `50-cloud-init.conf` с
`PasswordAuthentication yes`, который перебивает правки в основном файле.

Посмотреть, что там уже есть:

```bash
ls /etc/ssh/sshd_config.d/
sudo grep -r . /etc/ssh/sshd_config.d/
```

Создаём свой файл с именем, которое идёт **раньше** по алфавиту (`00-` < `50-`):

```bash
sudo vim /etc/ssh/sshd_config.d/00-hardening.conf
```

```sshconfig
PermitRootLogin no
PasswordAuthentication no
KbdInteractiveAuthentication no
PubkeyAuthentication yes
```

## Шаг 3. Проверить синтаксис и итоговые значения

```bash
sudo sshd -t   # пусто = ошибок нет
sudo sshd -T | grep -Ei 'permitrootlogin|passwordauthentication|kbdinteractive|pubkeyauthentication'
```

Ожидаемо:

```text
permitrootlogin no
pubkeyauthentication yes
passwordauthentication no
kbdinteractiveauthentication no
```

Если где-то `yes` — значит, его задаёт другой файл: найти через `sudo grep -ri passwordauth /etc/ssh/`.

## Шаг 4. Перезапустить SSH

```bash
sudo systemctl restart ssh
```

Текущая сессия не оборвётся.

## Шаг 5. Проверить (в новом терминале)

```bash
ssh vps                                    # ✅ должен зайти
ssh root@<IP>                              # ❌ Permission denied
ssh -o PubkeyAuthentication=no node@<IP>   # ❌ Permission denied (publickey)
```

Итог:

- ❌ root не может зайти
- ❌ вход по паролю отключён
- ✅ только ключи, только пользователь `node`

Пароль `node` остаётся нужен — для `sudo`.
