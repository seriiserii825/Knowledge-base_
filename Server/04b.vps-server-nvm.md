# Node.js через nvm (по желанию)

**Нужно ли это?** Если приложение запускается в Docker (`05.vps-server-docker.md`) — Node.js на самом сервере **не
нужен**, он есть внутри образа. nvm нужен, только если запускаете Node прямо на хосте (например, через pm2 —
`07.vps-server-pm2.md`).

Ставится под пользователем `node`, **без sudo**.

## Шаг 1. Установить nvm

Актуальную версию смотреть тут: <https://github.com/nvm-sh/nvm/releases> (подставить вместо `v0.40.3`).

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

## Шаг 2. Активировать nvm

```bash
source ~/.bashrc     # или ~/.zshrc, если shell — zsh
nvm --version
```

Или просто перезайти по SSH.

## Шаг 3. Установить Node.js

Ставить актуальную **LTS** (чётная версия: 22, 24, …):

```bash
nvm install --lts
nvm alias default lts/*
```

Или конкретную версию — ту же, что в проекте (`.nvmrc`, `engines` в `package.json`, `FROM node:XX` в Dockerfile):

```bash
nvm install 24
nvm alias default 24
```

## Шаг 4. Проверить

```bash
node -v
npm -v
which node   # → /home/node/.nvm/versions/node/...
```

## Заметки

- Node из nvm виден только пользователю `node` и только в интерактивном shell. Для systemd-сервисов и cron указывать
  полный путь (`which node`) или использовать pm2.
- Другие менеджеры пакетов: `corepack enable` (pnpm/yarn) или bun: `curl -fsSL https://bun.sh/install | bash`.
