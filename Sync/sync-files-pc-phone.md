# Передача больших файлов с ПК на телефон

Задача: скачать длинное видео (например, с YouTube через `yt-dlp`) и смотреть на телефоне офлайн. Через Telegram не всегда получается — лимит **2 ГБ** на файл (4 ГБ с Premium), плюс файл приходится сначала загрузить, а потом скачать обратно.

Решения ниже — от «передать напрямую» до «уменьшить файл».

## 1. Передача напрямую (без лимита по размеру)

### Если ПК без Wi‑Fi

Wi‑Fi на ПК не обязателен. Если ПК подключён к роутеру **кабелем**, а телефон — к **тому же роутеру по Wi‑Fi**, они уже в одной локальной сети, и все сетевые способы ниже работают.

Проверить IP ПК:
```bash
ip -4 a
```
Если у ПК `192.168.x.x` и у телефона адрес из того же диапазона (Настройки → Wi‑Fi → текущая сеть) — всё ок.

Пример (домашний ПК): кабель `enp6s0`, адрес `192.168.2.86/24` → на телефоне открывать `http://192.168.2.86:8000`.

IP телефона искать не обязательно — достаточно запустить HTTP-сервер и попробовать открыть адрес ПК в браузере телефона. Открылся список файлов — сеть общая.

### Где посмотреть IP на телефоне

- **Xiaomi 11T (MIUI/HyperOS):**
  - Настройки → Wi‑Fi → нажать на подключённую сеть (или `>` справа) → строка «IP-адрес» (иногда внизу, пролистать).
  - Или: Настройки → О телефоне → Подробная информация и характеристики → Статус → IP-адрес.
- **Android (общее):** Настройки → Wi‑Fi → шестерёнка у сети → «Дополнительно» / «Подробнее». Названия пунктов зависят от производителя.
- **iPhone:** Настройки → Wi‑Fi → ⓘ рядом с сетью → «IP-адрес».

Адрес должен быть из того же диапазона, что у ПК (например, `192.168.2.x`).

**«IP-адрес недоступен»** = телефон не подключён к Wi‑Fi (сидит на мобильном интернете). Варианты:
- подключить телефон к Wi‑Fi того же роутера, к которому кабелем подключён ПК — тогда IP появится;
- если роутер не раздаёт Wi‑Fi — использовать USB-кабель (MTP, см. ниже) или USB-модем.

### HTTP-сервер одной командой (ничего не надо ставить)

```bash
cd ~/Downloads && python -m http.server 8000
```
На телефоне в браузере: `http://<IP-ПК>:8000` → скачать файл. Работает и на Android, и на iPhone. Остановить сервер — `Ctrl+C`.

Если страница не открывается:
- файрвол: `sudo systemctl status ufw firewalld` — если активен, временно открыть порт: `sudo ufw allow 8000/tcp`;
- телефон в гостевой сети роутера (она изолирована от основной) — переключиться на основную;
- телефон вообще не в Wi‑Fi — см. «IP-адрес недоступен» выше.

### LocalSend

- ПК: `yay -S localsend-bin`
- Телефон: LocalSend из Play Store / App Store
- Оба устройства в одной сети → открыть приложение на обоих → перетащить файл → принять на телефоне.

### KDE Connect

Подходит, если уже установлен.

### USB-кабель как диск (MTP, только Android)

На телефоне после подключения выбрать режим «Передача файлов». На ПК:
```bash
sudo pacman -S gvfs-mtp   # если ещё не стоит
```
Телефон появится в файловом менеджере → скопировать видео, например, в `Movies`.

На Xiaomi (MIUI/HyperOS): шторка уведомлений → «Зарядка по USB» → «Передача файлов». Режим часто сбрасывается — выбирать заново при каждом подключении.

Проверить из терминала, что ПК видит телефон:
```bash
gio mount -li | grep -i -A3 mtp
```

### USB-кабель через adb (Android)

На телефоне включить «Отладку по USB» (в настройках для разработчиков).
```bash
sudo pacman -S android-tools
adb push video.mp4 /sdcard/Movies/
```

### USB-модем с телефона (если нет общей сети)

Подключить телефон кабелем → на телефоне включить «USB-модем». У ПК появится сетевой интерфейс — дальше HTTP-сервер или LocalSend, как выше. Работает и с iPhone (для него MTP не вариант).

### Что выбрать

- **Android** → USB-кабель (MTP): быстро и без настройки.
- **iPhone** → HTTP-сервер или LocalSend по общей сети, либо USB-модем + HTTP-сервер.

## 2. Уменьшить файл, чтобы влез в Telegram

### Скачивать сразу в 720p

Для телефона 720p обычно достаточно, а весит в разы меньше, чем 1080p/4K:
```bash
yt-dlp -f "bv*[height<=720]+ba/b[height<=720]" --merge-output-format mp4 URL
```

### Пережать уже скачанное видео

```bash
ffmpeg -i input.mp4 -c:v libx265 -crf 28 -preset medium -c:a aac -b:a 96k output.mp4
```
H.265 даёт файл примерно в 2 раза меньше при том же качестве, но кодирует медленно. Быстрее — `-c:v libx264 -crf 26`.

### Порезать на части без перекодирования

Каждая часть по часу (подобрать `-segment_time` так, чтобы части были < 2 ГБ):
```bash
ffmpeg -i input.mp4 -c copy -f segment -segment_time 3600 -reset_timestamps 1 part_%02d.mp4
```

## Рекомендация

Скачать в 720p через `yt-dlp` и передать напрямую — по кабелю (Android) или через HTTP-сервер/LocalSend. Это быстрее, чем гонять файл через Telegram.
