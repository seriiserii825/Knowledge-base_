# Claude Code CLI — названия сессий и возврат к ним

## /rename — название сессии

`/rename <название>` даёт текущей сессии название. Оно показывается:
- в окне ввода;
- в заголовке терминала;
- в списке сессий `/resume`.

То же самое можно задать сразу при запуске:

```bash
claude -n "название"        # или --name
```

## Как вернуться к сессии

| Команда | Что делает |
|---|---|
| `claude -r "название"` (или `--resume`) | открыть сессию по названию или ID |
| `claude -r` | список сессий: выбрать или поискать по названию |
| `claude -c` (или `--continue`) | сразу последняя сессия **в текущей папке**, без выбора |

## Сессии привязаны к папке

Claude Code хранит сессии отдельно для каждой папки, из которой их запускали:

```
~/.claude/projects/<путь к папке>/
```

Поэтому запускать сессию нужно **из той же папки**, где она начиналась: там `claude -r "название"` или `claude -r` и выбрать.

### Найти сессию из любой папки: `claude -r` → `Ctrl+A`

1. В любой папке запустить `claude -r`.
2. Внутри списка нажать `Ctrl+A` — покажутся **все** сессии на компьютере, а не только из текущей папки.
3. Выбрать сессию — Claude выдаст в терминал команду: в какую папку перейти и какую сессию запустить.

То есть искать сессию можно откуда угодно, а запускается она всё равно из своей папки — эту команду программа подсказывает сама.

(Этого нет в `claude --help` — узнал на практике.)

Важно: значение имеет папка, **из которой запущен** `claude`, а не та, где шла работа. Например, сессия `altuofianco-plugin-go-private` запущена из `~/Documents/go/go-wp`, хотя работа шла в основном в go-private. Возвращаться в неё так:

```bash
cd ~/Documents/go/go-wp
claude -r "altuofianco-plugin-go-private"
```

## Без /rename

Всё то же самое, только искать по началу разговора и времени:
- из той же папки `claude -r` и выбрать сессию в списке;
- или `claude -c`, если это была последняя сессия в этой папке.

## Одна сессия в нескольких терминалах

### Обычная сессия — по очереди, не одновременно

**Перейти в другой терминал можно:**
1. закрыть сессию в текущем терминале (`Ctrl+C` два раза или `/exit`);
2. на другом рабочем столе открыть терминал **в той же папке**;
3. `claude -r "название"` — разговор продолжится с того же места.

**Одновременно в двух терминалах — не стоит.** Если открыть ту же сессию вторым `claude -r`, пока первая ещё работает, это будут два отдельных процесса: они не видят сообщений друг друга, но пишут в одну историю — получится каша.

**Вторая параллельная сессия с тем же контекстом:**

```bash
claude -r "название" --fork-session
```

Создаёт копию под новым ID, две ветки живут отдельно.

### Фоновая сессия — подключаться из любого терминала

| Команда | Что делает |
|---|---|
| `claude --bg` | запустить сессию в фоне, выводит её ID |
| `claude attach <id или часть названия>` | открыть фоновую сессию в текущем терминале (название с пробелами — в кавычках) |
| `Ctrl+Z` | вернуться в shell, сессия **продолжает работать** |
| `claude agents` | список фоновых сессий |
| `claude --bg --resume <session-id>` | продолжить существующую сессию в фоне |

Сценарий: в одном терминале `claude attach …`, поработал, `Ctrl+Z` → в другом терминале снова `claude attach …` — и ты опять в той же сессии.

Если сессия в момент `--bg --resume` уже открыта в каком-то терминале, по справке будет создана копия (и программа об этом скажет).

Описание фонового режима — по `claude --help` и `claude attach --help`, на практике не проверено.
