# Свой минималистичный видеоплеер (замена smplayer) — план

## Зачем
smplayer избыточен. Нужно только: просмотр видео, перемотка, недавние папки/файлы, закладки (bookmarks) по времени внутри файла.
Система: Arch, X11, i3. `mpv` уже стоит (в нём есть `libmpv`).

## Оценка
- **Реалистично: да.** Декодирование, рендер, аппаратное ускорение, субтитры и аудиодорожки делает `libmpv` — пишем только оболочку (окно, меню, списки). ~600–900 строк Python.
- **Время (с Claude Code):** рабочая версия за одну сессию (~30–60 мин), доводка — ещё 1–2 короткие итерации.
- **Токены:** ~150–400 тыс. суммарно (в основном повторное чтение контекста), генерируемого кода ~20–40 тыс.

## Стек
**Python + PyQt6 + python-mpv** (обёртка над libmpv). C++/Qt быстрее стартует, но писать и править дольше — не стоит.

Пакеты:
```
sudo pacman -S python-pyqt6
yay -S python-mpv        # или venv + pip install python-mpv
```
Добавить в `~/dotfiles/packages/pacman.txt` / `eiwi.txt`.

## Функции
- `main.py` — QMainWindow со встроенным mpv (`mpv.MPV(wid=str(int(widget.winId())))`), полноэкранный режим.
- Управление: ползунок перемотки, play/pause, громкость. Клавиши как в mpv: ←/→ ±5 с, ↑/↓ ±60 с, Space — пауза, f — fullscreen, колесо — громкость.
- **Recent**: JSON в `~/.local/share/vplayer/state.json` — последние N файлов и папок + позиция воспроизведения (продолжение с места остановки).
- **Open folder**: открыть папку → плейлист из видео в ней, следующий/предыдущий файл.
- **Bookmarks**: `b` — добавить метку (файл + время + опц. имя); панель/меню со списком, клик → переход. Хранятся в том же JSON.
- Диалоги открытия — запускать с `QT_QPA_PLATFORMTHEME=xdgdesktopportal`, чтобы работал yazi через termfilechooser (как у Flameshot).
- По желанию: `.desktop`-файл + `xdg-mime default vplayer.desktop video/*`, биндинг в i3.

## Где хранить
`~/dotfiles/bin/vplayer/` или отдельный репозиторий — решить при старте.

## Проверка
- Открыть видео, перемотка клавишами и ползунком, fullscreen.
- Закрыть/открыть — файл в Recent, воспроизведение продолжается с того же места.
- Поставить 2–3 закладки, перезапустить, перейти по ним.
- Открыть папку — переключение next/prev.
