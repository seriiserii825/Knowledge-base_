### spam / не спам

Отдельной команды «spam» в aerc нет — это просто перемещение письма в папку спама (и обратно). Сервер (Gmail, Yandex, mail.ru) сам учится на таком перемещении, как будто нажал «Спам» в веб-интерфейсе.

```bash
:move <Tab>          - переместить письмо (или все помеченные v/Space) в папку, Tab дополняет имя
:move Spam<Enter>    - в спам (Yandex / mail.ru / hostinger — имя может быть Spam или Junk)
:move [Gmail]/Spam   - в спам (Gmail)
:move INBOX<Enter>   - вытащить из спама обратно во входящие (сначала зайти в спам: c Spam<Tab>)
:mv ...              - короткая форма :move
:cp <папка>          - скопировать вместо перемещения
```

Работает и в списке писем, и в открытом письме. Точное имя папки спама в каждом аккаунте видно в левой панели или через `c <Tab>`.

### compose / reply

```bash
c, m - написать новое
rr - ответить всем (:reply -a)
rq - ответить всем с цитатой (:reply -aq)
Rr - ответить только отправителю (:reply)
Rq - ответить только отправителю с цитатой (:reply -q)
# r = всем, R = только отправителю; вторая буква: r — без цитаты, q — с цитатой
b - bounce (переслать как есть)

alt+p / alt+n - переключить аккаунт-отправитель (внутри composer)

# вложения — на экране review (после :wq в редакторе)
a - выбрать файл(ы) через yazi (:attach -m), подтвердить — o (open), несколько — выделить Space
A <путь> - прикрепить по пути (:attach, Tab дополняет, можно маску ~/Downloads/*.pdf)
d - открепить
e - вернуться в редактор, y - отправить, p - в черновики
ctrl+x attach <путь> - прикрепить прямо из редактора (ctrl+x = ':' в compose)
tab / shift+tab - следующее/предыдущее поле формы
```

### view (открытое письмо)

```bash
ctrl+j / ctrl+k (ctrl+↓ / ctrl+↑) - следующая/предыдущая часть письма (plain / html / вложения)
o, O - открыть выбранную часть во внешней программе (html → браузер, pdf → просмотрщик)
S <Enter> - сохранить выбранную часть в ~/Downloads (default-save-path)
:save -a - сохранить все вложения письма разом
f - переслать
H - показать/скрыть все заголовки
ctrl+l - open-link
ctrl+y - copy-link
D - удалить
A - архивировать
q - закрыть просмотр
```

- `S` сохраняет **текущую выбранную часть**. Если выбрана `text/html` или `text/plain` — у неё нет имени, и файл сохранится как `aerc_<дата>` без расширения. Чтобы сохранить PDF, сначала ctrl+j до строки с `.pdf`.
- HTML-часть внутри aerc показывается через фильтр `text/html=! html` (`aerc.conf`), который вызывает **w3m** (текстовый браузер). Без него — ошибка `failed to execute w3m`. Ставится: `sudo pacman -S w3m`.

### флаги в списке писем (колонка слева от отправителя)

```bash
O / N - непрочитанное (old / new)
a - есть вложение (attachment)
! - помечено важным (flagged), снимается F / :unflag — прочтение его НЕ снимает
r - ты ответил
f - переслал
* - выделено (v/V/Space/ctrl+a)
```

Непрочитанные — значок `O` (old, непрочитанное с прошлой синхронизации) или `N` (new, только пришло). В стандартной теме они вообще никак не выделены (`msglist_unread.bold` там закомментирован), поэтому сделана своя тема `stylesets/mine` (`aerc.conf` → `styleset-name=mine`): непрочитанные **жирные жёлтые**, flagged (`!`) — красные. Ещё видно по счётчику у папки в левой панели (`INBOX 1`).

### search

```bash
/ - поиск
\ - фильтр
n / N - следующий/предыдущий результат
Esc - очистить поиск/фильтр (заодно снимает все выделения)
```

Фильтр/поиск по email (флаги одинаковые для `\` и `/`):

```bash
\-f user@example.com   - письма ОТ этого адреса (From)
\-t user@example.com   - письма ЭТОМУ адресу (To)
\-c user@example.com   - в копии (Cc)
\-f @example.com       - от всех с домена (подстрока)
\-u                    - только непрочитанные (= клавиша U)
/-u                    - прыгать по непрочитанным через n / N
\-f user -u            - от user и только непрочитанные
\-H Reply-To:user@x    - по любому заголовку
```

`\` (filter) оставляет в списке только совпавшие письма, `/` (search) только прыгает по ним через `n` / `N`. Esc возвращает полный список.

### заметки

- Аккаунты (gmail/yandex/hostinger/mail.ru) открываются как отдельные табы — переключение между ними это обычная навигация по табам (ctrl+n/ctrl+p), а не отдельная команда switch-account.
- Левая боковая панель (список папок) не отдельная focusable-панель — она просто отражает текущую папку. Переключение папок — J/K или `c <имя>`.
- Конфиг: `~/.config/aerc/{accounts.conf,aerc.conf,binds.conf}` → симлинк на `~/dotfiles/.config/aerc/`.
- `aerc.conf` → `[general] default-save-path=~/Downloads` — куда сохраняет `S` без пути.
- `aerc.conf` → `[compose] file-picker-cmd=yazi --chooser-file=%f` — yazi как выбор вложений (`:attach -m`, клавиша `a` на review).
- `accounts.conf` → `cache-headers = false` у всех аккаунтов. С кэшем (`~/.cache/aerc/<аккаунт>`) флаги устаревали: письмо на сервере непрочитанное (`INBOX 1`), а aerc показывал его прочитанным, без `O` и цвета. Если какой-то аккаунт станет медленным — вернуть ему `true`; при странных флагах — закрыть aerc и `rm -rf ~/.cache/aerc`.
- Свои биндинги в `binds.conf` → `[messages]`: `M` (всё прочитано), `F` (unflag), `U` (только непрочитанные), `ctrl+a` (выделить всё), `Esc` (+ unmark -a). `R` не занимать — это префикс для `Rr`/`Rq`.

### polybar-виджет почты

- Виджет (`~/dotfiles/.config/polybar/mail-count.sh`) считает непрочитанные через **mailnag** (D-Bus), а не через aerc.
- Левый клик — фокус на окно aerc (по заголовку `aerc`), если не запущен — `alacritty -T aerc -e aerc`. Если mailnag лежит — клик его запускает.
- Правый клик — mailnag проверяет почту сейчас (счётчик обновляется только при проверке, поэтому после прочтения в aerc может ещё гореть).
- Виджет горит, а в aerc не видно? Письмо может быть в другом аккаунте. Узнать в каком:
  ```bash
  busctl --user call mailnag.MailnagService /mailnag/MailnagService mailnag.MailnagService GetMails
  ```
  (в выводе `account_name`), потом в этом табе `U`.
- `accounts.conf` содержит пароли в открытом виде — в git уходит только зашифрованная версия `accounts.conf.gpg` (через `.gpgrc` + `go-lf push`), сам `accounts.conf` в `.gitignore`.
