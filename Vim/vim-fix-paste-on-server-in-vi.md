# Как исправить отступы при вставке в Vim на сервере

При вставке многострочного кода через терминал Vim может добавлять свой автоматический отступ к пробелам, которые уже есть в скопированном тексте. В итоге строки смещаются всё дальше вправо «лесенкой».

## Вставить текст без дополнительных отступов

1. Если вставка уже испорчена, нажми `Esc`, затем `u`, чтобы её отменить.
2. В обычном режиме Vim включи режим вставки текста без автоформатирования:

   ```vim
   :set paste
   ```

3. Перейди в режим вставки (`i`) и вставь текст через терминал.
4. После вставки нажми `Esc` и верни обычные настройки:

   ```vim
   :set nopaste
   ```

`paste` временно отключает автоматические отступы и некоторые другие настройки, которые мешают вставке через терминал. После `:set nopaste` они снова работают.

Проверить текущий режим можно командой `:set paste?`. Если выводит `paste`, режим включён; если `nopaste` — выключен.

Если вместо вставки через терминал используешь команду Vim `p` в обычном режиме, включать `paste` обычно не требуется.
