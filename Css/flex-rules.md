# Flexbox: flex vs width

Внутри `display: flex` можно использовать `width` и `flex`, но они работают по-разному.

## 1. Flex — управление шириной колонок

```scss
.container {
  display: flex;
  gap: 27px;
}

.main {
  flex: 1;
  min-width: 0;
}

.sidebar {
  flex: 0 0 578px;
}
```

- `flex: 1` — занимает всё оставшееся пространство.
- `flex: 0 0 578px` — фиксированная ширина 578px.
- `min-width: 0` — позволяет элементу сжиматься, даже если внутри длинный текст или широкое содержимое.

### Синтаксис flex

```css
flex: grow shrink basis;
```

| Свойство | Описание                       |
| -------- | ------------------------------ |
| `grow`   | Может ли элемент увеличиваться |
| `shrink` | Может ли элемент сжиматься     |
| `basis`  | Начальный размер элемента      |

### Частые варианты

```css
flex: 1; /* Занять свободное пространство */
flex: 0 0 300px; /* Фиксированная ширина 300px */
flex: 1 1 300px; /* Начальная ширина 300px, может расти и сжиматься */
flex: 0 1 300px; /* Начальная ширина 300px, может только сжиматься */
flex: 0 0 auto; /* Размер по содержимому или width, без изменения */
```

## 2. Width — установка ширины

```css
.sidebar {
  width: 300px;
}
```

Внутри flex-контейнера `width: 300px` не гарантирует фиксированную ширину, потому что по умолчанию `flex-shrink: 1`.

Чтобы запретить сжатие:

```css
.sidebar {
  width: 300px;
  flex-shrink: 0;
}
```

Это практически эквивалентно:

```css
.sidebar {
  flex: 0 0 300px;
}
```

## 3. Сравнение

| CSS                | Поведение                        |
| ------------------ | -------------------------------- |
| `width: 300px`     | Ширина 300px, но может сжиматься |
| `flex: 0 0 300px`  | Фиксированная ширина             |
| `flex: 1`          | Занимает оставшееся пространство |
| `flex: 1 1 300px`  | Может расти и сжиматься          |
| `flex: 0 1 300px`  | Может сжиматься, но не растёт    |
| `max-width: 300px` | Ограничивает максимальную ширину |

## 4. Адаптивная двухколоночная структура

```scss
.single-event {
  &__wrap {
    display: flex;
    gap: 27px;
  }

  &__main {
    flex: 1;
    min-width: 0;
  }

  &__sidebar {
    flex: 0 0 578px;
  }

  @media (max-width: 991px) {
    &__wrap {
      flex-direction: column;
    }

    &__sidebar {
      flex: auto;
      width: 100%;
    }
  }
}
```

## 5. Главное правило

- **`flex: 1`** — когда элемент должен занимать оставшееся место.
- **`flex: 0 0 300px`** — когда нужна фиксированная колонка.
- **`width: 300px`** — когда нужна заданная ширина, но допустимо сжатие.
- **`max-width`** — когда нужно ограничить максимальный размер.
- **`min-width: 0`** — для гибких колонок с содержимым, которое может вызывать переполнение.

**Рекомендация:** для построения колонок Flexbox используй `flex`, а для обычных элементов — `width` и `max-width`.
