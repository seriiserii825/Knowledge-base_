# Figma — горячие клавиши

Раскладка для Linux/Windows. На macOS: `Ctrl` → `Cmd`, `Alt` → `Option`.

Полный список прямо в Figma: `Ctrl+Shift+?`. Поиск любой команды по названию: `Ctrl+K`.

## Быстрый поиск слоя

Чтобы не скроллить панель Layers:

| Клавиши | Действие |
| --- | --- |
| `Ctrl+клик` по холсту | Сразу выделить вложенный слой, даже внутри инстанса |
| `ПКМ` → **Select layer** | Список всех слоёв под курсором |
| `Ctrl+F` | Найти слой по имени |
| `Alt+L` | Свернуть всё дерево слоёв |

**Приём:** `Alt+L`, затем `Ctrl+клик` по нужному элементу — раскроется только путь к нему.

## Выделение

| Клавиши | Действие |
| --- | --- |
| `Enter` | Выделить дочерние слои |
| `Shift+Enter` | Выделить родителя |
| `Tab` / `Shift+Tab` | Следующий / предыдущий соседний слой |
| `Ctrl+A` | Выделить всё |
| `Ctrl+Shift+A` | Инвертировать выделение |
| `Esc` | Снять выделение / выйти из режима редактирования |

## Редактирование слоёв

| Клавиши | Действие |
| --- | --- |
| `Ctrl+D` | Дублировать |
| `Ctrl+R` | Переименовать |
| `Ctrl+Shift+H` | Скрыть / показать |
| `Ctrl+Shift+L` | Заблокировать / разблокировать |

| `Ctrl+Alt+M` | Использовать как маску |
| `Стрелки` | Сдвиг на 1px |
| `Shift+стрелки` | Сдвиг на 10px |

## Порядок и выравнивание

| Клавиши | Действие |
| --- | --- |
| `Ctrl+]` / `Ctrl+[` | На слой выше / ниже |
| `Ctrl+Shift+]` / `Ctrl+Shift+[` | На передний / задний план |
| `Alt+A` / `Alt+D` | Выровнять по левому / правому краю |
| `Alt+W` / `Alt+S` | Выровнять по верхнему / нижнему краю |
| `Alt+H` / `Alt+V` | Центрировать по горизонтали / вертикали |
| `Ctrl+Alt+T` | Tidy up |

## Группы, фреймы, компоненты

| Клавиши | Действие |
| --- | --- |
| `Ctrl+G` | Сгруппировать |
| `Ctrl+Shift+G` | Разгруппировать |
| `Ctrl+Alt+G` | Обернуть выделенное во фрейм |
| `Shift+A` | Добавить auto layout |
| `Ctrl+Alt+K` | Создать компонент |
| `Ctrl+Alt+B` | Detach instance (отвязать от компонента) |

> Внутри инстанса `Ctrl+G` не работает: структуру инстанса менять нельзя, только свойства слоёв.
> Группировать нужно в главном компоненте или после detach.

## Мышь + клавиша

| Клавиши | Действие |
| --- | --- |
| `Alt` + наведение | Показать расстояние до соседних объектов |
| `Alt` + тянуть | Дублировать объект |
| `Shift` + тянуть | Двигать строго по оси, сохранять пропорции при ресайзе |
| `Alt` + ресайз | Менять размер от центра |
| `Space` при рисовании | Двигать фигуру, не заканчивая её |
| `Ctrl` + тянуть | Не прилипать к родительскому фрейму при перетаскивании |
