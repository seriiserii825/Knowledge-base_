# Figma — токен в `.env`

Как добавить Personal Access Token для расширения `chrome-figma-copy`
(`~/Documents/chrome-extensions/chrome-figma-copy`).

Токен нужен для `Alt+C` и кнопок «Извлечь шрифты» / «Извлечь цвета» в popup.
Хоткеям `ct`, `cl` и `cs` он не нужен.

## 1. Создать токен

1. В Figma нажми на аватар → **Settings** → вкладка **Security**.
2. Найди **Personal access tokens** → **Generate new token**.
3. Задай имя и срок действия.
4. В **Scopes** для **File content** выбери **Read only** (`file_content:read`).
   Остальное оставь **No access**.
5. Нажми **Generate token** и сразу скопируй: Figma показывает токен один раз.

## 2. Добавить в `.env`

Файл лежит в корне расширения:

```bash
cd ~/Documents/chrome-extensions/chrome-figma-copy
nvim .env
```

Содержимое — одна строка, без кавычек:

```env
FIGMA_TOKEN=figd_твой_токен
```

Настоящий токен сюда, в заметку, не вставлять.

## 3. Обновить расширение

1. Открой `chrome://extensions/` и нажми значок перезагрузки на карточке расширения.
2. Открой popup: должно появиться сообщение `Токен загружен из .env.`

Токен из `.env` важнее сохранённого вручную в popup.

## 4. Зашифровать

`.env` в `.gitignore`, в репозиторий попадает только `.env.gpg` (он указан в `.gpgrc`).

- `git-push.sh` шифрует файл сам через `encryptFiles`.
- `git-pull.sh` и `git-clone.sh` расшифровывают его через `decryptFiles`.

Вручную:

```bash
rm -f .env.gpg && gpg -e -r "$USER" .env   # зашифровать
gpg -d .env.gpg > .env                     # расшифровать
```

## Ошибки

| Сообщение | Что делать |
| --- | --- |
| `.env найден, но в нём нет FIGMA_TOKEN.` | Проверь имя переменной и формат строки |
| `Сначала сохрани Personal Access Token.` | `.env` не найден: создай его или введи токен в popup |
| `Токен недействителен или просрочен...` | Создай новый токен и повтори шаги 2–4. Ошибка 403 бывает и при нехватке прав на файл |
| Вместо имён переменных показываются id | Нужен доступ `file_variables:read`, а API переменных есть не на всех тарифах. Цвета всё равно копируются с hex |
