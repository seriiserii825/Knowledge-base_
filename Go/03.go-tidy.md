# Go — Установка и управление зависимостями

## 1. Установка пакетов

В Go для добавления внешних библиотек используется `go get`.

```bash
go get github.com/google/uuid
```

Установленная зависимость добавляется в `go.mod`.

Установить конкретную версию:

```bash
go get github.com/google/uuid@v1.6.0
```

Обновить зависимость до последней версии:

```bash
go get github.com/google/uuid@latest
```

Для установки CLI-инструментов отдельно от зависимостей проекта:

```bash
go install example.com/tool/cmd/tool@latest
```

## 2. go mod tidy

Команда синхронизирует зависимости с исходным кодом:

```bash
go mod tidy
```

Что делает:

- Добавляет недостающие зависимости.
- Удаляет неиспользуемые зависимости.
- Обновляет `go.mod` и `go.sum`.

Рекомендуется запускать после изменения внешних импортов.

## 3. go.mod и go.sum

**go.mod** — описание модуля и его зависимостей.

```go
module github.com/seriiserii825/go-course

go 1.25.0

require github.com/google/uuid v1.6.0
```

**go.sum** — файл с контрольными суммами зависимостей.

- Создаётся автоматически при необходимости.
- Проверяет целостность скачанных модулей.
- Не требует ручного запуска.
- Должен храниться в Git вместе с `go.mod`.

## 4. Полезные команды

| Команда                   | Назначение                              |
| ------------------------- | --------------------------------------- |
| `go mod init <name>`      | Создать модуль                          |
| `go get <package>`        | Добавить зависимость                    |
| `go get <package>@latest` | Обновить зависимость                    |
| `go mod tidy`             | Очистить и синхронизировать зависимости |
| `go mod download`         | Скачать зависимости в кэш               |
| `go list -m all`          | Показать зависимости                    |
| `go mod verify`           | Проверить скачанные зависимости         |
| `go env GOMOD`            | Показать путь к текущему `go.mod`       |

## 5. Пример использования

```bash
# Перейти в проект
cd ~/Documents/go-course

# Добавить библиотеку
go get github.com/google/uuid

# Привести зависимости в порядок
go mod tidy

# Проверить изменения
git status

# Сохранить изменения
git add go.mod go.sum
git commit -m "chore: update Go dependencies"
```

**Важно:** `go mod tidy` анализирует весь модуль, включая тесты.
Если библиотека больше нигде не используется, её зависимость будет удалена.

**Сравнение с JavaScript:**

- `go.mod` ≈ `package.json`
- `go.sum` ≈ часть функций `package-lock.json`
- `go get` ≈ `npm install`
- `go mod tidy` — нет прямого аналога в npm.
