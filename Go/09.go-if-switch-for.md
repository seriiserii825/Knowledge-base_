# 05. Условия и циклы в Go

В Go используются `if`, `else`, `switch`, `for` и `range` для управления выполнением программы.

## 1. if / else

Условия записываются без круглых скобок.

```go
age := 20

if age >= 18 {
    fmt.Println("Adult")
} else if age >= 13 {
    fmt.Println("Teenager")
} else {
    fmt.Println("Child")
}
```

Можно объявить переменную прямо в условии:

```go
if score := 85; score >= 60 {
    fmt.Println("Passed")
}
```

`score` доступна только внутри конструкции `if / else`.

## 2. switch

Аналог `switch` в JavaScript, но `break` не нужен.

```go
day := "Monday"

switch day {
case "Monday":
    fmt.Println("Start of week")
case "Saturday", "Sunday":
    fmt.Println("Weekend")
default:
    fmt.Println("Workday")
}
```

### switch без переменной

```go
score := 85

switch {
case score >= 90:
    fmt.Println("Excellent")
case score >= 60:
    fmt.Println("Passed")
default:
    fmt.Println("Failed")
}
```

`fallthrough` позволяет перейти к следующему `case` без проверки его условия.

## 3. for

В Go нет `while` и `do...while`. Используется только `for`.

### Обычный цикл

```go
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```

### Аналог while

```go
count := 0

for count < 5 {
    fmt.Println(count)
    count++
}
```

### Бесконечный цикл

```go
for {
    fmt.Println("Running")
    break
}
```

- `break` — завершает цикл.
- `continue` — пропускает текущую итерацию.

## 4. range

`range` используется для перебора массивов, срезов, строк и map.

### Срез (slice)

```go
names := []string{"Alex", "John", "Mike"}

for index, name := range names {
    fmt.Println(index, name)
}
```

Только значения:

```go
for _, name := range names {
    fmt.Println(name)
}
```

Только индексы:

```go
for index := range names {
    fmt.Println(index)
}
```

### Map

```go
user := map[string]string{
    "name": "Alex",
    "city": "London",
}

for key, value := range user {
    fmt.Println(key, value)
}
```

Порядок перебора `map` не гарантируется.

### Строка

```go
for index, char := range "Привет" {
    fmt.Printf("%d: %c\n", index, char)
}
```

`index` — позиция в байтах, `char` — Unicode-символ (`rune`).

## 5. Отличия от JavaScript

| JavaScript   | Go              |
| ------------ | --------------- |
| `if (x > 5)` | `if x > 5`      |
| `else if`    | `else if`       |
| `switch`     | `switch`        |
| `for`        | `for`           |
| `while`      | `for condition` |
| `for...of`   | `for range`     |
| `for...in`   | `for range`     |
| `break`      | `break`         |
| `continue`   | `continue`      |

**Важно:**

- В Go нет тернарного оператора `? :`.
- Условия `if` должны иметь тип `bool`.
- В `switch` автоматически прекращается выполнение после выбранного `case`.
- `range` для строк перебирает Unicode-символы, а не байты.
