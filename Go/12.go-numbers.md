## 2. Арифметические операции и деление

### Основные операции

```go
a, b := 10, 3

fmt.Println(a + b) // 13
fmt.Println(a - b) // 7
fmt.Println(a * b) // 30
fmt.Println(a / b) // 3
fmt.Println(a % b) // 1
```

### Деление целых чисел (int / int)

Если оба числа имеют тип `int`, результат тоже будет `int`.

**Дробная часть отбрасывается, а не округляется.**

```go
fmt.Println(10 / 3) // 3
fmt.Println(10 / 4) // 2
fmt.Println(11 / 2) // 5
```

Например:

```go
a := 10
b := 4

result := a / b

fmt.Println(result) // 2
fmt.Printf("%T", result) // int
```

Математически `10 / 4 = 2.5`, но Go возвращает `2`.

Отбрасывание происходит в сторону нуля:

```go
a, b := -10, 4

fmt.Println(a / b) // -2, не -3
```

### Деление с дробной частью (float64)

Чтобы получить дробный результат, нужно использовать `float64`.

```go
a := 10.0
b := 4.0

result := a / b

fmt.Println(result) // 2.5
fmt.Printf("%T", result) // float64
```

Если переменные имеют тип `int`, преобразуй их:

```go
a := 10
b := 4

result := float64(a) / float64(b)

fmt.Println(result) // 2.5
```

**Важно:** преобразование нужно сделать ДО деления.

```go
a, b := 10, 4

// Неправильно
result1 := float64(a / b) // 2.0

// Правильно
result2 := float64(a) / float64(b) // 2.5
```

В первом случае сначала выполняется целочисленное деление, и только потом результат преобразуется в `float64`.

### Смешивание int и float64

Go не позволяет автоматически смешивать переменные разных числовых типов.

```go
a := 10      // int
b := 4.5     // float64

// result := a / b // Ошибка компиляции

result := float64(a) / b // 2.222...
```

### Остаток от деления (%)

Оператор `%` возвращает остаток от целочисленного деления.

```go
fmt.Println(10 % 3) // 1
fmt.Println(10 % 2) // 0
fmt.Println(15 % 4) // 3
```

Полезно для проверки чётности:

```go
number := 8

if number%2 == 0 {
    fmt.Println("Even")
} else {
    fmt.Println("Odd")
}
```

Для дробных чисел используй `math.Mod()`.

### Деление на ноль

При целочисленном делении на ноль возникает паника во время выполнения, если делитель — переменная со значением 0.

```go
a, b := 10, 0

if b != 0 {
    fmt.Println(a / b)
} else {
    fmt.Println("Division by zero!")
}
```

Для `float64` деление на ноль может возвращать `+Inf`, `-Inf` или `NaN` по правилам IEEE 754.

### Сравнение с JavaScript

```javascript
10 / 4; // 2.5
```

```go
a, b := 10, 4

fmt.Println(a / b)                   // 2
fmt.Println(float64(a) / float64(b)) // 2.5
```

**Запомни:**

- `int / int` → `int`, дробная часть отбрасывается.
- `float64 / float64` → `float64`.
- `float64(a / b)` — дробная часть уже потеряна.
- `float64(a) / float64(b)` — правильное дробное деление.
- `%` — остаток от целочисленного деления.
- Перед целочисленным делением проверяй делитель на ноль.
