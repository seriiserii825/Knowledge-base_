# 04. Работа со строками в Go

Основные пакеты: `strings`, `strconv`, `fmt`, `unicode/utf8`.

## 1. Длина строки

```go
len("Hello") // 5 (байты)
len("Привет") // 12 (байты)
utf8.RuneCountInString("Привет") // 6 (символы)
```

## 2. Регистр и сравнение

```go
strings.ToUpper("hello") // "HELLO"
strings.ToLower("HELLO") // "hello"
strings.EqualFold("HELLO", "hello") // true (без учёта регистра)
"hello" == "hello" // true (с учётом регистра)
```

## 3. Поиск

```go
strings.Contains("Hello Go", "Go") // true
strings.HasPrefix("Hello", "He") // true
strings.HasSuffix("Hello", "lo") // true
strings.Index("Hello Go", "Go") // 6 (-1 если не найдено)
strings.Count("banana", "a") // 3
```

## 4. Замена и удаление

```go
strings.Replace("aaa", "a", "b", 1) // "baa"
strings.ReplaceAll("aaa", "a", "b") // "bbb"
strings.TrimSpace(" Hi ") // "Hi"
strings.Trim("!!Hi!!", "!") // "Hi"
strings.TrimPrefix("Hello", "He") // "llo"
strings.TrimSuffix("Hello", "lo") // "Hel"
```

## 5. Разделение и объединение

```go
strings.Split("Go,JS,PHP", ",") // []string{"Go", "JS", "PHP"}
strings.Join([]string{"Go", "JS"}, "-") // "Go-JS"
strings.Repeat("Go", 3) // "GoGoGo"
```

## 6. Часть строки

```go
text := "Hello World"
text[:5] // "Hello"
text[6:] // "World"
```

```go
// Unicode
  chars := []rune("Привет")
string(chars[:3]) // "При"
```

## 7. Преобразование типов (strconv)

```go
num, \_ := strconv.Atoi("123") // string → int
str := strconv.Itoa(123)
```
