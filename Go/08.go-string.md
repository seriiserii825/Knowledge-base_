# 04. Работа со строками в Go

В Go строки имеют тип `string`. Для работы со строками используется стандартный пакет `strings`.

```go
import (
    "fmt"
    "strings"
)
```

## 1. Длина строки

```go
text := "Hello"

fmt.Println(len(text)) // 5
```

`len()` возвращает количество байт, а не символов Unicode.

```go
fmt.Println(len("Привет"))         // 12
fmt.Println(utf8.RuneCountInString("Привет")) // 6
```

Для подсчёта символов импортируй `unicode/utf8`.

## 2. Изменение регистра

```go
strings.ToUpper("hello") // HELLO
strings.ToLower("HELLO") // hello
```

## 3. Поиск в строке

```go
text := "Hello Golang"

strings.Contains(text, "Go")    // true
strings.HasPrefix(text, "Hello") // true
strings.HasSuffix(text, "lang")  // true
strings.Index(text, "Go")        // 6
```

`Index()` возвращает `-1`, если совпадение не найдено.

## 4. Замена текста

```go
text := "Hello World World"

strings.Replace(text, "World", "Go", 1)
// Hello Go World

strings.ReplaceAll(text, "World", "Go")
// Hello Go Go
```

## 5. Удаление пробелов

```go
strings.TrimSpace("  Hello  ") // "Hello"
strings.Trim("!!Hello!!", "!") // "Hello"
strings.TrimPrefix("Hello", "He") // "llo"
strings.TrimSuffix("Hello", "lo") // "Hel"
```

## 6. Разделение и объединение

```go
words := strings.Split("Go,JS,PHP", ",")
// []string{"Go", "JS", "PHP"}

result := strings.Join(words, " | ")
// Go | JS | PHP
```

## 7. Повторение строки

```go
strings.Repeat("Go ", 3)
// "Go Go Go "
```

## 8. Сравнение строк

```go
strings.EqualFold("HELLO", "hello") // true

"hello" == "hello" // true
```

`EqualFold()` сравнивает без учёта регистра.

## 9. Подсчёт совпадений

```go
strings.Count("banana", "a") // 3
```

## 10. Получение части строки

```go
text := "Hello World"

fmt.Println(text[0:5]) // Hello
fmt.Println(text[6:])  // World
```

Индексы работают с байтами. Для Unicode-символов:

```go
text := "Привет"
chars := []rune(text)

fmt.Println(string(chars[0:3])) // При
```

## 11. Преобразование строки

Используется пакет `strconv`.

```go
import "strconv"

num, _ := strconv.Atoi("123") // string → int
str := strconv.Itoa(123)      // int → string

price, _ := strconv.ParseFloat("19.99", 64)
active, _ := strconv.ParseBool("true")
```

В реальном коде ошибки преобразования нужно проверять.

## 12. Форматирование строк

```go
name := "Alex"
age := 25

result := fmt.Sprintf("Name: %s, Age: %d", name, age)
fmt.Println(result)
```

Основные спецификаторы:

- `%s` — строка
- `%d` — целое число
- `%f` — дробное число
- `%.2f` — два знака после запятой
- `%t` — boolean
- `%v` — любое значение
- `%%` — символ процента

## Важно

- Строки в Go неизменяемые (immutable).
- Функции `strings` возвращают новую строку, не изменяя исходную.
- `len()` считает байты.
- `[]rune` используется для работы с Unicode-символами.
- `strings.Builder` удобен для эффективного объединения большого количества строк.
