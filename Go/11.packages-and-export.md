# 07. Пакеты и экспорт функций в Go

В Go код разделяется на пакеты (`package`). Функции из одного файла можно вызывать в другом.

## 1. Функции внутри одного пакета

Если файлы находятся в одной папке и используют одинаковый `package`, функции доступны без импорта.

Структура:

```text
go-course/
├── go.mod
├── main.go
└── utils.go
```

**utils.go**

```go
package main

func sayHello(name string) string {
    return "Hello, " + name
}
```

**main.go**

```go
package main

import "fmt"

func main() {
    fmt.Println(sayHello("Alex"))
}
```

Запуск:

```bash
go run .
```

Важно: `go run main.go` не подключит `utils.go`. Используй `go run .`.

## 2. Экспорт функций из другого пакета

Для доступа к функциям из другого пакета имя должно начинаться с **большой буквы**.

Структура:

```text
go-course/
├── go.mod
├── main.go
└── utils/
    └── strings.go
```

**go.mod**

```go
module github.com/seriiserii825/go-course
```

**utils/strings.go**

```go
package utils

import "strings"

// Экспортируемая функция
func ToUpper(text string) string {
    return strings.ToUpper(text)
}

// Приватная функция пакета
func toLower(text string) string {
    return strings.ToLower(text)
}
```

**main.go**

```go
package main

import (
    "fmt"
    "github.com/seriiserii825/go-course/utils"
)

func main() {
    fmt.Println(utils.ToUpper("hello")) // HELLO

    // utils.toLower("HELLO") // Ошибка
}
```

## 3. Правила доступа

| Имя          | Внутри пакета | Другой пакет |
| ------------ | ------------- | ------------ |
| `sayHello()` | ✅            | ❌           |
| `SayHello()` | ✅            | ✅           |
| `userName`   | ✅            | ❌           |
| `UserName`   | ✅            | ✅           |

Правило распространяется на функции, переменные, константы, типы и поля структур.

## 4. Сравнение с JavaScript

**JavaScript**

```javascript
// utils.js
export function sayHello() {
  return "Hello";
}

// main.js
import { sayHello } from "./utils.js";
```

**Go**

```go
// utils/hello.go
package utils

func SayHello() string {
    return "Hello"
}
```

```go
// main.go
package main

import "github.com/seriiserii825/go-course/utils"

func main() {
    println(utils.SayHello())
}
```

## 5. Алиасы импортов

Пакету можно назначить другое имя:

```go
import helper "github.com/seriiserii825/go-course/utils"

func main() {
    println(helper.SayHello())
}
```

## Главное

- `package` — объединяет файлы в логическую группу.
- Файлы одного пакета могут использовать функции друг друга.
- `func hello()` — доступна только внутри пакета.
- `func Hello()` — экспортируется в другие пакеты.
- `import` — подключает пакет по его пути.
- `go.mod` — определяет путь модуля.
- `go run .` — запускает пакет из текущей директории.
- В Go нет ключевых слов `export`, `public` и `private`.
