# Форматирование через `fmt.Printf`

| Формат | Назначение                                |
| ------ | ----------------------------------------- |
| `%s`   | Строка                                    |
| `%d`   | Целое число                               |
| `%f`   | Дробное число                             |
| `%.2f` | Дробное число с двумя знаками после точки |
| `%t`   | Boolean                                   |
| `%T`   | Тип переменной                            |
| `%v`   | Значение в стандартном формате            |
| `%q`   | Строка в кавычках                         |
| `\n`   | Перенос строки                            |

Пример определения типа:

```go
name := "Sergey"
age := 30

fmt.Printf("%T\n", name) // string
fmt.Printf("%T\n", age)  // int
```

## вывести несколько переменных в одной строке

```go
name := "Sergei"
age := 30
fmt.Printf("Name: %s, Age: %d\n", name, age)
```
