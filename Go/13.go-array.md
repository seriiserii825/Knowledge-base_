# 09. Массивы, Slices и Maps в Go

В Go используются `array`, `slice` и `map` для хранения коллекций данных.

## 1. Array — массив

Массив имеет фиксированную длину, которая является частью его типа.

```go
numbers := [3]int{10, 20, 30}

fmt.Println(numbers[0])  // 10
fmt.Println(len(numbers)) // 3
```

Автоматическое определение длины:

```go
names := [...]string{"Alex", "John", "Mike"}
```

`[...]` означает, что Go сам определит длину массива по количеству элементов.

```go
[3]int    // массив из 3 элементов
[...]int  // длину определяет компилятор
[]int     // slice — динамическая коллекция
```

**Важно:** длина массива не изменяется. В большинстве случаев лучше использовать `slice`.

## 2. Slice — динамический массив

Аналог `Array` из JavaScript.

```go
numbers := []int{10, 20, 30}

fmt.Println(numbers[0])  // 10
fmt.Println(len(numbers)) // 3
```

### Добавление элементов — append()

```go
numbers = append(numbers, 40, 50)

// [10 20 30 40 50]
```

`append()` возвращает обновлённый slice, поэтому результат нужно присваивать.

### Получение части slice

```go
numbers := []int{10, 20, 30, 40, 50}

fmt.Println(numbers[1:3]) // [20 30]
fmt.Println(numbers[:2])  // [10 20]
fmt.Println(numbers[2:])  // [30 40 50]
```

Правая граница не включается.

### Удаление элемента

```go
numbers := []int{10, 20, 30, 40}

i := 1

numbers = append(numbers[:i], numbers[i+1:]...)

// [10 30 40]
```

## 3. make — создание Slice

`make()` — встроенная функция Go для создания `slice`, `map` и `channel`.

### Создание с готовыми элементами

```go
numbers := make([]int, 3)

fmt.Println(numbers)      // [0 0 0]
fmt.Println(len(numbers)) // 3
fmt.Println(cap(numbers)) // 3
```

`3` — длина (`len`). Элементы автоматически заполняются нулями.

### Создание с запасом памяти

```go
numbers := make([]int, 0, 10)

fmt.Println(numbers)      // []
fmt.Println(len(numbers)) // 0
fmt.Println(cap(numbers)) // 10
```

- `0` — количество существующих элементов.
- `10` — вместимость, заранее выделенная память.

```go
numbers = append(numbers, 10, 20)

fmt.Println(numbers)      // [10 20]
fmt.Println(len(numbers)) // 2
fmt.Println(cap(numbers)) // 10
```

Пока хватает `cap`, добавление не требует выделения нового базового массива.

### Разница len и cap

```go
make([]int, 5)     // len=5, cap=5
make([]int, 0, 10) // len=0, cap=10
make([]int, 5, 10) // len=5, cap=10
```

- `len()` — количество доступных элементов.
- `cap()` — вместимость базового массива, доступная slice.
- `append()` — добавляет элементы, при необходимости увеличивая вместимость.

### Slice без make

```go
a := []int{}
b := make([]int, 0, 100)
```

Оба варианта позволяют использовать `append()`.

`make()` полезен, когда заранее известно примерное количество элементов.

## 4. Map — объект с ключами

`map` хранит пары `ключ → значение`.

Аналог `Record` или `Map` из JavaScript/TypeScript.

### Создание map с данными

```go
user := map[string]string{
    "name": "Alex",
    "city": "London",
}

fmt.Println(user["name"]) // Alex
```

`map[string]string` означает:

- первый `string` — тип ключа;
- второй `string` — тип значения.

### Создание пустой map

```go
user := map[string]string{}
```

Или через `make()`:

```go
user := make(map[string]string)
```

**Оба способа создают пустую map, готовую к записи.**

### Добавление и изменение

```go
user := make(map[string]string)

user["name"] = "Alex"
user["city"] = "London"

user["city"] = "Paris"
```

### Удаление

```go
delete(user, "city")
```

### Проверка существования ключа

```go
name, exists := user["name"]

if exists {
    fmt.Println(name)
}
```

Если ключ отсутствует, возвращается нулевое значение типа.

## 5. make для Map

```go
users := make(map[string]int, 100)

fmt.Println(len(users)) // 0
```

`100` — подсказка о предполагаемом количестве записей, а не начальная длина.

```go
users["Alex"] = 25

fmt.Println(len(users)) // 1
```

**Отличие от slice:**

- `make([]int, 5)` создаёт slice с 5 элементами.
- `make(map[string]int, 5)` создаёт пустую map с подсказкой о размере.
- `cap()` для map не существует.

### nil map

```go
var user map[string]string

fmt.Println(user["name"]) // ""

// Ошибка во время выполнения (panic)
user["name"] = "Alex"
```

`nil map` можно читать, но нельзя добавлять в неё элементы.

Для записи сначала создай map:

```go
user = make(map[string]string)
user["name"] = "Alex"
```

## 6. Map или Struct?

В `map[string]string` все значения должны быть строками.

```go
user := map[string]string{
    "name": "Alex",
    "age":  "25",
}
```

Если нужны разные типы данных, обычно используют `struct`.

```go
type User struct {
    Name   string
    Age    int
    Active bool
}

user := User{
    Name:   "Alex",
    Age:    25,
    Active: true,
}

fmt.Println(user.Name) // Alex
```

`struct` ближе к типизированному объекту или interface в TypeScript.

## 7. Перебор через range

### Slice

```go
names := []string{"Alex", "John"}

for index, name := range names {
    fmt.Println(index, name)
}
```

Если индекс не нужен:

```go
for _, name := range names {
    fmt.Println(name)
}
```

### Map

```go
scores := map[string]int{
    "Alex": 100,
    "John": 85,
}

for key, value := range scores {
    fmt.Println(key, value)
}
```

Порядок перебора `map` не гарантируется.

## 8. Полезные функции

### Slice

```go
nums := []int{10, 20, 30}

len(nums)                  // 3
cap(nums)                  // вместимость
nums = append(nums, 40)    // добавить элемент
clear(nums)                // обнулить элементы
```

`clear(slice)` не изменяет его длину.

### Map

```go
user := map[string]string{"name": "Alex"}

len(user)            // 1
delete(user, "name") // удалить ключ
clear(user)          // удалить все записи
```

## 9. Сравнение с JavaScript / TypeScript

| JavaScript / TypeScript  | Go                     |
| ------------------------ | ---------------------- |
| `number[]`               | `[]int`                |
| `[1, 2, 3]`              | `[]int{1, 2, 3}`       |
| `arr.push(4)`            | `arr = append(arr, 4)` |
| `arr.length`             | `len(arr)`             |
| `arr.slice(1, 3)`        | `arr[1:3]`             |
| `Record<string, number>` | `map[string]int`       |
| `new Map()`              | `make(map[string]int)` |
| `delete obj.key`         | `delete(m, "key")`     |
| `interface User`         | `struct User`          |
| `for...of`               | `for range`            |

## Главное

- `array` — массив фиксированной длины.
- `[...]int` — Go сам определяет длину массива.
- `[]int` — динамический slice, аналог JS Array.
- `append()` — добавляет элементы в slice.
- `len()` — количество элементов.
- `cap()` — вместимость slice.
- `make()` — создаёт slice, map или channel.
- `map` — коллекция ключ → значение.
- `map[string]int{}` — пустая map.
- `make(map[string]int)` — тоже пустая map.
- `make(map[string]int, 100)` — пустая map с подсказкой о размере.
- `var m map[string]int` — nil map, запись вызовет panic.
- `delete()` — удаляет ключ из map.
- `struct` — для объектов с полями разных типов.
