# 14. Slice в Go

`slice` — динамическая коллекция элементов одного типа. Аналог `Array` из JavaScript/TypeScript.

## 1. Создание slice

```go
numbers := []int{10, 20, 30}

fmt.Println(numbers[0])  // 10
fmt.Println(len(numbers)) // 3
```

Пустой slice:

```go
var numbers []int   // nil slice
numbers := []int{}   // пустой, но не nil
```

## 2. make — создание slice

`make()` — встроенная функция для создания `slice` (а также `map` и `channel`).

### Создание с готовыми элементами

```go
numbers := make([]int, 3)

fmt.Println(numbers)      // [0 0 0]
fmt.Println(len(numbers)) // 3
fmt.Println(cap(numbers)) // 3
```

`3` — длина (`len`). Элементы автоматически заполняются нулями.

### Создание с запасом памяти

```go
numbers := make([]int, 0, 10)

fmt.Println(numbers)      // []
fmt.Println(len(numbers)) // 0
fmt.Println(cap(numbers)) // 10
```

- `0` — количество существующих элементов.
- `10` — вместимость, заранее выделенная память.

```go
numbers = append(numbers, 10, 20)

fmt.Println(numbers)      // [10 20]
fmt.Println(len(numbers)) // 2
fmt.Println(cap(numbers)) // 10
```

Пока хватает `cap`, добавление не требует выделения нового базового массива.

### Разница len и cap

```go
make([]int, 5)     // len=5, cap=5
make([]int, 0, 10) // len=0, cap=10
make([]int, 5, 10) // len=5, cap=10
```

- `len()` — количество доступных элементов.
- `cap()` — вместимость базового массива, доступная slice.
- `append()` — добавляет элементы, при необходимости увеличивая вместимость.

## 3. Добавление элементов — append()

```go
numbers := []int{10, 20, 30}

numbers = append(numbers, 40, 50)

// [10 20 30 40 50]
```

`append()` возвращает обновлённый slice, поэтому результат нужно присваивать.

### Добавление одного slice в другой

```go
a := []int{1, 2}
b := []int{3, 4}

a = append(a, b...)

// [1 2 3 4]
```

## 4. Получение части slice

```go
numbers := []int{10, 20, 30, 40, 50}

fmt.Println(numbers[1:3]) // [20 30]
fmt.Println(numbers[:2])  // [10 20]
fmt.Println(numbers[2:])  // [30 40 50]
```

Правая граница не включается.

## 5. Удаление элемента

```go
numbers := []int{10, 20, 30, 40}

i := 1

numbers = append(numbers[:i], numbers[i+1:]...)

// [10 30 40]
```

## 6. copy — копирование slice

```go
src := []int{1, 2, 3}
dst := make([]int, len(src))

copy(dst, src)

// dst: [1 2 3]
```

Присваивание `dst := src` не копирует данные — оба slice указывают на один базовый массив.

## 7. Перебор через range

```go
names := []string{"Alex", "John"}

for index, name := range names {
    fmt.Println(index, name)
}
```

Если индекс не нужен:

```go
for _, name := range names {
    fmt.Println(name)
}
```

## 8. Двумерный slice

```go
matrix := [][]int{
    {1, 2, 3},
    {4, 5, 6},
}

fmt.Println(matrix[1][2]) // 6
```

## 9. Полезные функции

```go
nums := []int{10, 20, 30}

len(nums)                  // 3
cap(nums)                  // вместимость
nums = append(nums, 40)    // добавить элемент
clear(nums)                // обнулить элементы
```

`clear(slice)` не изменяет его длину.

Пакет `slices` (с Go 1.21):

```go
import "slices"

slices.Contains(nums, 20) // true
slices.Index(nums, 30)    // индекс элемента
slices.Sort(nums)         // сортировка по возрастанию
slices.Reverse(nums)      // разворот порядка
```

## 10. Сравнение с JavaScript / TypeScript

| JavaScript / TypeScript | Go                     |
| ------------------------ | ---------------------- |
| `number[]`               | `[]int`                |
| `[1, 2, 3]`              | `[]int{1, 2, 3}`       |
| `arr.push(4)`            | `arr = append(arr, 4)` |
| `arr.length`             | `len(arr)`             |
| `arr.slice(1, 3)`        | `arr[1:3]`             |
| `[...a, ...b]`           | `append(a, b...)`      |
| `arr.includes(x)`        | `slices.Contains(arr, x)` |
| `arr.sort()`             | `slices.Sort(arr)`     |
| `for...of`               | `for range`            |

## Главное

- `[]int` — динамический slice, аналог JS Array.
- `make([]int, len, cap)` — создаёт slice с заданной длиной и вместимостью.
- `append()` — добавляет элементы, возвращает новый slice.
- `len()` — количество элементов, `cap()` — вместимость.
- `numbers[a:b]` — получение части slice, правая граница не включается.
- `copy()` — копирует элементы между slice.
- `clear()` — обнуляет элементы без изменения длины.
- Пакет `slices` содержит готовые функции: `Contains`, `Index`, `Sort`, `Reverse`.
