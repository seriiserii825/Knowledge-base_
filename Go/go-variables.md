# Урок 2. Variables — Переменные в Go

## 1. Объявление переменных

В Go существует несколько способов объявить переменную.

### Способ 1. `var` с указанием типа

```go
package main

import "fmt"

func main() {
    var name string = "Sergey"
    var age int = 30
    var active bool = true

    fmt.Println(name, age, active)
}
```

Здесь мы явно указываем тип каждой переменной.

### Способ 2. `var` без указания типа

Go автоматически определяет тип по значению.

```go
var name = "Sergey"
var age = 30
var active = true
```

Типы будут `string`, `int` и `bool`.

### Способ 3. `:=` — короткое объявление

Самый распространённый способ внутри функций.

```go
func main() {
    name := "Sergey"
    age := 30
    active := true

    fmt.Println(name, age, active)
}
```

**Важно:**

- `:=` используется только внутри функций.
- Слева должна быть хотя бы одна новая переменная.
- Для изменения существующей переменной используется `=`.

---

## 2. Сравнение с JavaScript

| JavaScript                  | Go                        |
| --------------------------- | ------------------------- |
| `let name = "Sergey"`       | `name := "Sergey"`        |
| `const age = 30`            | `const age = 30`          |
| `let age = 30`              | `var age int = 30`        |
| `age = "hello"` — разрешено | Ошибка: нельзя менять тип |
| `let x;` → `undefined`      | `var x int` → `0`         |

В Go действует **строгая статическая типизация**.

```go
age := 30

age = 31      // OK
age = "hello" // Ошибка компиляции
```

Тип переменной определяется при компиляции и не может изменяться.

---

## 3. Основные типы данных

| Тип       | Пример    | Назначение                               |
| --------- | --------- | ---------------------------------------- |
| `string`  | `"Hello"` | Строка                                   |
| `int`     | `25`      | Целое число                              |
| `int64`   | `1000000` | 64-битное целое число                    |
| `float64` | `19.99`   | Дробное число                            |
| `bool`    | `true`    | Логическое значение                      |
| `byte`    | `65`      | Псевдоним `uint8`                        |
| `rune`    | `'Ж'`     | Псевдоним `int32`, кодовая точка Unicode |

### Пример

```go
package main

import "fmt"

func main() {
    name := "Sergey"
    age := 30
    price := 99.99
    isAdmin := false

    fmt.Printf("Name: %s\n", name)
    fmt.Printf("Age: %d\n", age)
    fmt.Printf("Price: %.2f\n", price)
    fmt.Printf("Admin: %t\n", isAdmin)
}
```

### Форматирование через `fmt.Printf`

| Формат | Назначение                                |
| ------ | ----------------------------------------- |
| `%s`   | Строка                                    |
| `%d`   | Целое число                               |
| `%f`   | Дробное число                             |
| `%.2f` | Дробное число с двумя знаками после точки |
| `%t`   | Boolean                                   |
| `%T`   | Тип переменной                            |
| `%v`   | Значение в стандартном формате            |
| `%q`   | Строка в кавычках                         |
| `\n`   | Перенос строки                            |

Пример определения типа:

```go
name := "Sergey"
age := 30

fmt.Printf("%T\n", name) // string
fmt.Printf("%T\n", age)  // int
```

## 4. Изменение переменных

В Go можно менять значения переменных с помощью `=`.

```go
func main() {
    count := 10

    count = 20
    count += 5
    count++

    fmt.Println(count) // 26
}
```

### Сравнение с JavaScript

JavaScript:

```javascript
let count = 10;
count += 5;
count++;
```

Go:

```go
count := 10
count += 5
count++
```

**Важно:** `:=` объявляет новую переменную, а `=` изменяет существующую.

```go
age := 30 // Объявление
age = 31  // Изменение
```

---

## 5. Константы — `const`

Константа не может изменяться после объявления.

```go
const appName = "My CLI"
const maxUsers = 100
```

Попытка изменения приведёт к ошибке:

```go
const maxUsers = 100

maxUsers = 200 // Ошибка компиляции
```

В отличие от JavaScript, Go-константы могут быть только значениями, вычисляемыми во время компиляции.

Например, числами, строками и булевыми значениями.

---

## 6. Несколько переменных одновременно

### Групповое объявление через `var`

```go
var (
    name = "Sergey"
    age  = 30
    city = "Chisinau"
)
```

### Короткое объявление

```go
name, age := "Sergey", 30

fmt.Println(name, age)
```

### Обмен значениями

В Go можно поменять значения двух переменных без дополнительной переменной.

```go
a, b := 10, 20

a, b = b, a

fmt.Println(a, b) // 20 10
```

---

## 7. Нулевые значения — Zero Values

В JavaScript переменная, объявленная через `let` без значения, получает `undefined`.

В Go каждая переменная имеет значение по умолчанию.

| Тип                     | Значение по умолчанию |
| ----------------------- | --------------------- |
| `string`                | `""`                  |
| `int`                   | `0`                   |
| `float64`               | `0`                   |
| `bool`                  | `false`               |
| Указатели, срезы, карты | `nil`                 |

Пример:

```go
package main

import "fmt"

func main() {
    var age int
    var name string
    var active bool
    var price float64

    fmt.Printf("age: %d\n", age)       // 0
    fmt.Printf("name: %q\n", name)     // ""
    fmt.Printf("active: %t\n", active) // false
    fmt.Printf("price: %f\n", price)   // 0.000000
}
```

**Важно:** если объявить переменную без значения, Go автоматически присвоит ей нулевое значение соответствующего типа.

---

## 8. Неиспользуемые переменные

В Go нельзя объявлять локальные переменные и оставлять их неиспользованными.

Этот код не скомпилируется:

```go
func main() {
    name := "Sergey"
}
```

Ошибка:

```text
declared and not used: name
```

### Как исправить?

Использовать переменную:

```go
func main() {
    name := "Sergey"

    fmt.Println(name)
}
```

Или намеренно проигнорировать значение с помощью `_`:

```go
name, age := "Sergey", 30

_ = age

fmt.Println(name)
```

Символ `_` называется **blank identifier**.

Он используется, когда результат не нужен.

## 9. Практическое задание

Создать папку `02-variables` внутри проекта `go-course`.

```text
go-course/
├── go.mod
├── 01-go-install/
│   └── main.go
└── 02-variables/
    └── main.go
```

Новый `go mod init` не нужен, поскольку обе папки находятся внутри одного Go-модуля.

### Задача

Написать программу, которая:

1. Создаёт переменные `name`, `age`, `language`, `experience`, `isLearning`.
2. Использует минимум три разных типа данных.
3. Выводит значения переменных через `fmt.Printf`.
4. Выводит тип каждой переменной через `%T`.
5. Увеличивает `experience` на `1`.
6. Объявляет константу `courseName` со значением `"Go Course"`.

### Пример результата

```text
Course: Go Course
Name: Sergey
Age: 30
Language: Go
Experience: 2
Learning: true

Types:
name: string
age: int
language: string
experience: int
isLearning: bool
```

### Запуск

Из корня проекта:

```bash
go run ./02-variables
```

### Дополнительное задание

Объявить две переменные:

```go
a, b := 10, 20
```

Поменять значения местами без использования третьей переменной.

Ожидаемый результат:

```text
a: 20
b: 10
```

## 10. Краткая шпаргалка

```go
// Объявление с типом
var age int = 30

// Объявление с автоматическим определением типа
var name = "Sergey"

// Короткое объявление
city := "Chisinau"

// Изменение значения
age = 31

// Константа
const appName = "My App"

// Несколько переменных
a, b := 10, 20

// Обмен значениями
a, b = b, a

// Нулевое значение
var count int // 0

// Вывод значения
fmt.Println(name)

// Форматированный вывод
fmt.Printf("Age: %d\n", age)

// Определение типа
fmt.Printf("%T\n", age)

// Игнорирование значения
_ = city
```

### Главное запомнить

- `var` — объявление переменной.
- `:=` — короткое объявление внутри функции.
- `=` — изменение значения.
- `const` — неизменяемая константа.
- Go автоматически определяет тип, если он не указан.
- Тип переменной после объявления изменить нельзя.
- Переменные имеют нулевые значения по умолчанию.
- Неиспользуемые локальные переменные вызывают ошибку компиляции.
