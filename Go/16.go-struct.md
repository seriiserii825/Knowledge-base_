# 16. Struct в Go

`struct` — набор полей разных типов, объединённых в один тип. Ближе всего к типизированному объекту или `interface` в TypeScript.

## 1. Зачем нужен struct

В `map[string]string` все значения должны быть строками:

```go
user := map[string]string{
    "name": "Alex",
    "age":  "25",
}
```

Если нужны разные типы данных, используют `struct`:

```go
type User struct {
    Name   string
    Age    int
    Active bool
}

user := User{
    Name:   "Alex",
    Age:    25,
    Active: true,
}

fmt.Println(user.Name) // Alex
```

## 2. Создание структур

С именованными полями (порядок не важен):

```go
user := User{Name: "Alex", Age: 25}
```

Без имён полей (порядок обязателен, применяется редко):

```go
user := User{"Alex", 25, true}
```

Пустая структура — поля получают нулевые значения:

```go
var user User

fmt.Println(user) // { 0 false}
```

## 3. Указатель на структуру

```go
user := &User{Name: "Alex", Age: 25}

fmt.Println(user.Name) // Alex — Go сам разыменовывает указатель
```

`new()` создаёт указатель на структуру с нулевыми значениями:

```go
user := new(User)
user.Name = "Alex"
```

## 4. Методы структур

Метод — функция с получателем (`receiver`).

### Получатель по значению

```go
func (u User) Greet() string {
    return "Hello, " + u.Name
}

user := User{Name: "Alex"}
fmt.Println(user.Greet()) // Hello, Alex
```

Копия структуры передаётся в метод, изменения внутри метода не влияют на оригинал.

### Получатель по указателю

```go
func (u *User) SetName(name string) {
    u.Name = name
}

user := User{Name: "Alex"}
user.SetName("John")

fmt.Println(user.Name) // John
```

Используй указатель, если метод должен изменять структуру или структура большая (чтобы не копировать).

## 5. Вложенные структуры

```go
type Address struct {
    City string
}

type User struct {
    Name    string
    Address Address
}

user := User{
    Name:    "Alex",
    Address: Address{City: "London"},
}

fmt.Println(user.Address.City) // London
```

## 6. Встраивание (embedding)

Go не поддерживает классическое наследование, но поддерживает встраивание:

```go
type Animal struct {
    Name string
}

func (a Animal) Speak() string {
    return a.Name + " makes a sound"
}

type Dog struct {
    Animal
    Breed string
}

dog := Dog{Animal: Animal{Name: "Rex"}, Breed: "Labrador"}

fmt.Println(dog.Name)     // Rex — поле Animal доступно напрямую
fmt.Println(dog.Speak())  // Rex makes a sound — метод Animal доступен напрямую
```

## 7. Теги структур (struct tags)

Теги используются для сериализации, например в JSON:

```go
type User struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}
```

```go
import "encoding/json"

user := User{Name: "Alex", Age: 25}
data, _ := json.Marshal(user)

fmt.Println(string(data)) // {"name":"Alex","age":25}
```

## 8. Сравнение структур

Структуры можно сравнивать через `==`, если все поля сравнимы:

```go
a := User{Name: "Alex", Age: 25}
b := User{Name: "Alex", Age: 25}

fmt.Println(a == b) // true
```

Если структура содержит `slice` или `map`, сравнение через `==` не скомпилируется.

## 9. Slice и map структур

```go
users := []User{
    {Name: "Alex", Age: 25},
    {Name: "John", Age: 30},
}

for _, u := range users {
    fmt.Println(u.Name)
}
```

Подробнее о `slice` — в [[14.go-slice]], о `map` — в [[15.go-map]].

## 10. Сравнение с JavaScript / TypeScript

| JavaScript / TypeScript | Go                              |
| ------------------------ | -------------------------------- |
| `interface User { ... }` | `type User struct { ... }`       |
| `class User { ... }`     | `struct` + методы с receiver     |
| `extends`                | embedding (встраивание)          |
| `new User()`             | `User{}` или `new(User)`         |
| `this.name`              | `u.Name` (receiver)              |
| `JSON.stringify(obj)`    | `json.Marshal(obj)` + теги       |

## Главное

- `struct` — тип для объектов с полями разных типов.
- Поля создаются через `type Name struct { ... }`.
- Методы добавляются через receiver: `func (u User) Method()`.
- Receiver по значению — копия, по указателю (`*User`) — изменяет оригинал.
- Встраивание (embedding) заменяет наследование.
- Теги (`` `json:"name"` ``) управляют сериализацией.
- Структуры сравнимы через `==`, если не содержат slice/map.
