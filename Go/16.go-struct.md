# 16. Struct в Go

`struct` — набор полей разных типов, объединённых в один тип. Ближе всего к типизированному объекту или `interface` в TypeScript.

## 1. Зачем нужен struct

В `map[string]string` все значения должны быть строками:

```go
user := map[string]string{
    "name": "Alex",
    "age":  "25",
}
```

Если нужны разные типы данных, используют `struct`:

```go
type User struct {
    Name   string
    Age    int
    Active bool
}

user := User{
    Name:   "Alex",
    Age:    25,
    Active: true,
}

fmt.Println(user.Name) // Alex
```

## 2. Создание структур

С именованными полями (порядок не важен):

```go
user := User{Name: "Alex", Age: 25}
```

Без имён полей (порядок обязателен, применяется редко):

```go
user := User{"Alex", 25, true}
```

Пустая структура — поля получают нулевые значения:

```go
var user User

fmt.Println(user) // { 0 false}
```

## 3. Указатель на структуру

```go
user := &User{Name: "Alex", Age: 25}

fmt.Println(user.Name) // Alex — Go сам разыменовывает указатель
```

`new()` создаёт указатель на структуру с нулевыми значениями:

```go
user := new(User)
user.Name = "Alex"
```

## 4. Методы структур

Метод — функция с получателем (`receiver`).

### Получатель по значению

```go
func (u User) Greet() string {
    return "Hello, " + u.Name
}

user := User{Name: "Alex"}
fmt.Println(user.Greet()) // Hello, Alex
```

Копия структуры передаётся в метод, изменения внутри метода не влияют на оригинал.

### Получатель по указателю

```go
func (u *User) SetName(name string) {
    u.Name = name
}

user := User{Name: "Alex"}
user.SetName("John")

fmt.Println(user.Name) // John
```

Используй указатель, если метод должен изменять структуру или структура большая (чтобы не копировать).

## 5. Вложенные структуры

```go
type Address struct {
    City string
}

type User struct {
    Name    string
    Address Address
}

user := User{
    Name:    "Alex",
    Address: Address{City: "London"},
}

fmt.Println(user.Address.City) // London
```

## 6. Встраивание (embedding)

Go не поддерживает классическое наследование, но поддерживает встраивание:

```go
type Animal struct {
    Name string
}

func (a Animal) Speak() string {
    return a.Name + " makes a sound"
}

type Dog struct {
    Animal
    Breed string
}

dog := Dog{Animal: Animal{Name: "Rex"}, Breed: "Labrador"}

fmt.Println(dog.Name)     // Rex — поле Animal доступно напрямую
fmt.Println(dog.Speak())  // Rex makes a sound — метод Animal доступен напрямую
```

## 7. Теги структур (struct tags)

Теги используются для сериализации, например в JSON:

```go
type User struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}
```

```go
import "encoding/json"

user := User{Name: "Alex", Age: 25}
data, _ := json.Marshal(user)

fmt.Println(string(data)) // {"name":"Alex","age":25}
```

## 8. Сравнение структур

Структуры можно сравнивать через `==`, если все поля сравнимы:

```go
a := User{Name: "Alex", Age: 25}
b := User{Name: "Alex", Age: 25}

fmt.Println(a == b) // true
```

Если структура содержит `slice` или `map`, сравнение через `==` не скомпилируется.

## 9. Slice и map структур

```go
users := []User{
    {Name: "Alex", Age: 25},
    {Name: "John", Age: 30},
}

for _, u := range users {
    fmt.Println(u.Name)
}
```

Подробнее о `slice` — в [[14.go-slice]], о `map` — в [[15.go-map]].

## 10. Инкапсуляция: приватные поля, конструктор, геттеры/сеттеры

Поле с маленькой буквы (`name`) видно только внутри своего пакета — снаружи его нельзя ни прочитать, ни записать (подробнее — в [[11.packages-and-export]]). Доступ даём через экспортируемые функции и методы.

Структура проекта:

```
go-mod-study/
├── go.mod        // module study
├── main.go
└── user/
    └── user.go
```

`user/user.go`:

```go
package user

type User struct {
	name string // приватные поля
	age  int
}

// Конструктор — обычная функция, по соглашению New<Type>
func NewUser(name string, age int) User {
	if name == "" {
		return User{}
	}
	if age < 0 || age > 150 {
		return User{}
	}
	return User{
		name: name,
		age:  age,
	}
}

// Сеттеры — receiver по указателю, иначе изменится копия
func (u *User) SetName(name string) {
	if name != "" {
		u.name = name
	}
}

func (u *User) SetAge(age int) {
	if age >= 0 && age <= 150 {
		u.age = age
	}
}

// Геттеры
func (u *User) GetName() string {
	return u.name
}

func (u *User) GetAge() int {
	return u.age
}
```

`main.go` — импорт по пути `<module>/<папка>`:

```go
package main

import (
	"fmt"
	"study/user"
)

func main() {
	u := user.NewUser("Alice", 30)
	fmt.Println(u, "u") // {Alice 30} u

	u.SetName("Bob")
	u.SetAge(25)
	fmt.Println(u, "u") // {Bob 25} u

	name := u.GetName()
	age := u.GetAge()
	fmt.Println(name, "name") // Bob name
	fmt.Println(age, "age")   // 25 age
}
```

Что важно:

- Из `main` нельзя обратиться к полю напрямую — не скомпилируется:

  ```go
  u.name = "Bob"                     // u.name undefined (cannot refer to unexported field name)
  u := user.User{name: "Bob"}        // cannot refer to unexported field name in struct literal of type user.User
  ```

  `user.User{}` (без полей) создать можно — получится пустой `User`, в обход проверок конструктора.

- `NewUser` возвращает значение (`User`), а методы объявлены на `*User`. Вызов `u.SetName(...)` всё равно работает: `u` — переменная, и Go сам берёт адрес (`(&u).SetName(...)`). А вот на результате функции напрямую — нет, он не адресуемый:

  ```go
  user.NewUser("Alice", 30).SetName("Bob") // cannot call pointer method SetName on user.User
  ```

- `fmt.Println(u)` печатает и приватные поля (`{Bob 25}`) — `fmt` читает их через рефлексию, это не нарушает инкапсуляцию в коде.

- Идиоматично в Go геттеры называют без `Get`: `u.Name()`, а не `u.GetName()`. Сеттеры — с `Set`: `u.SetName()`.

- При невалидных данных `NewUser` молча возвращает пустой `User{}`. Идиоматичнее вернуть ошибку:

  ```go
  func NewUser(name string, age int) (User, error) {
  	if name == "" {
  		return User{}, errors.New("name is empty")
  	}
  	return User{name: name, age: age}, nil
  }

  u, err := user.NewUser("", 30)
  if err != nil {
  	fmt.Println(err) // name is empty
  }
  ```

## 11. Сравнение с JavaScript / TypeScript

| JavaScript / TypeScript | Go                              |
| ------------------------ | -------------------------------- |
| `interface User { ... }` | `type User struct { ... }`       |
| `class User { ... }`     | `struct` + методы с receiver     |
| `extends`                | embedding (встраивание)          |
| `new User()`             | `User{}` или `new(User)`         |
| `this.name`              | `u.Name` (receiver)              |
| `private name`           | поле с маленькой буквы (`name`)  |
| `constructor()`          | функция `NewUser()`              |
| `JSON.stringify(obj)`    | `json.Marshal(obj)` + теги       |

## Главное

- `struct` — тип для объектов с полями разных типов.
- Поля создаются через `type Name struct { ... }`.
- Методы добавляются через receiver: `func (u User) Method()`.
- Receiver по значению — копия, по указателю (`*User`) — изменяет оригинал.
- Встраивание (embedding) заменяет наследование.
- Теги (`` `json:"name"` ``) управляют сериализацией.
- Структуры сравнимы через `==`, если не содержат slice/map.
- Поля с маленькой буквы приватны для пакета — доступ через конструктор `NewX()` и методы.
