# 06. Функции в Go

Функции объявляются через `func`. Они могут принимать параметры и возвращать одно или несколько значений.

## 1. Объявление функции

```go
func greet() {
    fmt.Println("Hello!")
}

func main() {
    greet()
}
```

В отличие от JavaScript, используется `func`, а не `function`.

## 2. Параметры

Тип параметра указывается после имени.

```go
func greet(name string) {
    fmt.Println("Hello,", name)
}

greet("Alex")
```

Несколько параметров:

```go
func sum(a int, b int) int {
    return a + b
}

// Сокращённая запись
func sum(a, b int) int {
    return a + b
}
```

## 3. Возвращаемые значения

Тип результата указывается после параметров.

```go
func multiply(a, b int) int {
    return a * b
}

result := multiply(5, 3)
fmt.Println(result) // 15
```

Если функция ничего не возвращает, тип результата не указывается.

## 4. Несколько возвращаемых значений

Go позволяет возвращать несколько значений.

```go
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("division by zero")
    }

    return a / b, nil
}

result, err := divide(10, 2)

if err != nil {
    fmt.Println(err)
    return
}

fmt.Println(result) // 5
```

Игнорирование значения:

```go
result, _ := divide(10, 2)
```

## 5. Именованные возвращаемые значения

```go
func calculate(a, b int) (sum, product int) {
    sum = a + b
    product = a * b
    return
}

s, p := calculate(5, 3)
// 8, 15
```

Можно использовать обычный `return sum, product` — зачастую он понятнее.

## 6. Variadic — любое количество аргументов

`...` позволяет передать произвольное количество аргументов одного типа.

```go
func sum(numbers ...int) int {
    total := 0

    for _, n := range numbers {
        total += n
    }

    return total
}

sum(1, 2, 3) // 6
sum(5, 10)   // 15
```

Передача среза:

```go
nums := []int{1, 2, 3}
result := sum(nums...)
```

## 7. Анонимные функции

Аналог JavaScript function expressions.

```go
multiply := func(a, b int) int {
    return a * b
}

fmt.Println(multiply(3, 4)) // 12
```

Немедленный вызов:

```go
func() {
    fmt.Println("Hello!")
}()
```

## 8. Функция как аргумент

```go
func calculate(a, b int, operation func(int, int) int) int {
    return operation(a, b)
}

result := calculate(5, 3, func(a, b int) int {
    return a + b
})

fmt.Println(result) // 8
```

## 9. defer

`defer` откладывает выполнение вызова до завершения функции.

```go
func example() {
    defer fmt.Println("Second")
    fmt.Println("First")
}

// First
// Second
```

Часто используется для закрытия файлов и освобождения ресурсов.

## 10. Отличия от JavaScript

| JavaScript               | Go                               |
| ------------------------ | -------------------------------- |
| `function test()`        | `func test()`                    |
| `const fn = () => {}`    | `fn := func() {}`                |
| `return value`           | `return value`                   |
| Необязательная типизация | Типы обязательны                 |
| `...args`                | `args ...int`                    |
| Деструктуризация         | Несколько return                 |
| `try/catch`              | Обычно `error` и `if err != nil` |
| Нет прямого аналога      | `defer`                          |

**Важно:**

- В Go нет параметров по умолчанию.
- Функции могут возвращать несколько значений.
- Для ошибок обычно возвращают тип `error`.
- `func main()` — точка входа в исполняемую программу.
- Имена с большой буквы экспортируются из пакета.
- Аргументы передаются по значению (копируются); срезы, map и указатели позволяют работать с общими данными.
